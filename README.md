# HOUSTON
## Server Application for KSP mission control
## Host and control the Crew of your mission or join someone else to become Houston.

### Screens
- Pilot Info
- Flight Computer
- Craft Info
- Systems Info
- Cameras
- Parts Lookup
- Checklists
- Import Flight Computer
- Session Settings

### Planned Features
- Multiple Connections to Host: You and your flight officers take control of different aspects of the flight throughout the course of the mission
- Consistent Connection: Stay connected between flights
- Multiple Info Screens: Multiple screens containing information for calculating burns, showing trajectories, running science experiments, contract missions, ship info
- Comms and LOS: Communications and Loss Of Signal

- Part Failure Support:
